첫 화면의 헥스 덤프는 장식이 아니라 **실제 이미지 데이터**입니다.

## 첫 화면은 어떻게 그려지나

`assets/hero.jpg`를 캔버스에 그린 뒤, 화면 폭에 맞춰 정한 격자(열 × 행)로 줄여서 픽셀을 읽습니다. 그다음 `hexdump -C` 형식의 한 줄을 만들 때:

- 각 바이트 값 = 그 글자 위치에 있는 픽셀의 **밝기**(0x00–0xff)
- 각 글자의 색 = 그 위치 픽셀의 **색**
- 오른쪽 `|...|` 열 = 같은 바이트를 ASCII로 디코딩한 것 (중간 밝기는 출력 가능한 문자, 아주 밝거나 어두운 곳은 `.`)

즉 덤프를 텍스트로 복사하면 그 자체로 흑백 이미지의 raw 데이터가 됩니다. 덤프 위에 마우스를 올리면 해당 바이트의 offset·값·원래 RGB가 아래에 표시됩니다.

```c
// 밝기 계산 (Rec. 709)
uint8_t lum = 0.2126 * r + 0.7152 * g + 0.0722 * b;
```

## 구조

빌드 도구 없는 정적 사이트입니다.

| 파일 | 역할 |
|---|---|
| `site.json` | 블로그 제목, 소개, 링크, 첫 화면 이미지 |
| `posts/posts.json` | 글 목록 (제목·날짜·태그·요약) |
| `posts/<slug>.md` | 글 본문 (마크다운) |
| `about.md` | 오른쪽 위 `about` 버튼으로 열리는 이력서 |
| `assets/hero.jpg` | 첫 화면 이미지 — 바꾸면 덤프도 바뀜 |

첫 화면 이미지를 바꾸고 싶으면 `assets/hero.jpg`만 교체하면 됩니다.
